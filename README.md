# Sprint_6

## UI-автотесты для учебного сервиса "Яндекс Самокат"

## Описание проекта:

conftest.py - фикстура driver(): запуск браузера (Firefox), открытие сайта, закрытие после каждого теста
urls.py - адреса сайтов
data.py - тестовые данные
locators/ - локаторы элементов страниц
pages/base_page.py - базовый класс: wait-хелперы, форматирование локаторов
pages/main_page.py - методы главной страницы (FAQ, кнопки заказа, логотипы)
pages/order_page.py - методы формы заказа (заполнение, подтверждение)
tests/test_main_page.py - тесты FAQ (раскрытие вопросов и тексты ответов)
tests/test_order_page.py - оформление заказа (2 набора данных, 2 кнопки), переходы по логотипам
